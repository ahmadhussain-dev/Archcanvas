# Blueprint3D Babylon: User Guide & Manual

Welcome to **Blueprint3D Babylon Panoramic Home Design System**! This guide is designed to help you master step-by-step how to use this professional interior design system integrating 2D floorplan drafting and 3D photorealistic rendering.

---

## 📂 Table of Contents

For ease of navigation and systematic learning, the manual is divided into five core feature modules:

1. **[Project Management & File Export](01_file_and_system.md)**:
   Master creating, saving, local and auto-backup recovery, and multi-format exports (JSON, ZIP asset packages, CAD DXF drawings, watertight 3MF 3D printing models).
2. **[Floorplan Drafting & Structural Design](02_structure_design.md)**:
   Learn 2D wall drawing, smart grid snapping, automatic enclosed area generation, and rapid placement and adjustment of custom doors/windows, stairs, and smart opening railings.
3. **[Material Styling & Surface Painting](03_material_paint.md)**:
   Learn to use the eyedropper and paint bucket for room-aware painting, uploading custom material textures, and enabling smart UV tiling anti-stretch compensation.
4. **[Furniture Arrangement & Smart Appliances](04_furniture_arrangement.md)**:
   Understand gravity-snapping surface attachment, one-click automatic bookshelf filling, and interactive audiovisual effects & physical animations triggered by appliance power toggles.
5. **[Camera Navigation & Advanced Rendering](05_view_and_render.md)**:
   Experience first-person WASD navigation with collision detection, discover right-click pick proxies for hidden objects, multi-level planar reflections, and reflection probe parallax correction.

## ⌨️ Shortcut Keys Reference

Using shortcut keys effectively enhances your design efficiency. Below is an overview of core shortcut actions:

| Shortcut | Mode / Feature | Description |
| --- | --- | --- |
| **Space** | Select Mode | Default pointer mode, used to select rooms, walls, or furniture and edit properties in the right panel. |
| **V** | Pan / View Mode | Pan canvas mode, used to drag and pan the 2D view without accidentally selecting objects. |
| **L** | Draw Wall Mode | Draw physical walls by clicking vertices in 2D view. |
| **E** | Erase Wall Mode | Activates eraser cursor; click any wall segment to delete it quickly. |
| **I** | Material Eyedropper | Penetrates complex furniture to extract exact component material under cursor. |
| **B** | Material Brush | Paints selected material onto individual furniture/component surfaces clicked by cursor. |
| **G** | Smart Paint Bucket | Room-level large surface painting, or one-click batch material sync across same-type furniture. |
| **C** | Material Eraser | Clears custom materials on selected surface, restoring factory default material. |
| **Ctrl + Z** | Undo | Roll back to previous operation (history stack supports up to **80 steps**). |
| **Ctrl + Y** | Redo | Re-apply previously undone design steps. |
| **Ctrl + S** | Quick Save | Manually overwrite current local project data. |
| **F12** | Snapshot 📷 | Capture ultra-HD screenshot of 3D viewport (without UI overlay). |
